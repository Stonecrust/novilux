NOVILUX PERSONAL WEBSITE
========================

FILES
- index.html: website content and page structure
- styles.css: responsive layout, colors, typography, and animations
- script.js: mobile navigation behavior
- assets/novilux-portrait.png: uploaded official portrait
- assets/novilux-logo.png: uploaded Novilux logo

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.

TO PUBLISH
Upload the contents of this folder to a static hosting service or your web host.
Keep the assets folder next to index.html.

CUSTOMIZE BEFORE LAUNCH
- Check that each social handle and link is correct.
- Confirm the biography and service descriptions accurately represent your experience.
- The site uses Google Fonts when internet access is available and falls back to Arial/Helvetica.
- Email links open the visitor's default email app.
